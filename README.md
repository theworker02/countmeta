# countmeta

Count structured JSON meta payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/countmeta/

## Install / run

```bash
git clone https://github.com/theworker02/countmeta.git
cd countmeta
node src/cli.js
node --test
```
